# ADR-0023：完全主机权限下的长时开发采用 fail-closed 安全边界

- 状态：Accepted
- 日期：2026-08-12

## 背景

当前开发会话被授予完整文件系统与进程权限，并需要持续完成多个基础设施切片。
权限能力不等同于对任意系统或外部副作用的授权。长时任务如果把便利性当作授权，
容易留下后台服务、扩大删除范围、泄露本机凭据，或在没有人工决定时执行远端发布。

## 决定

1. 完整主机权限只用于用户明确范围内的 JobSlayer workspace、只读环境检查，以及
   名称固定为 `/var/tmp/jobslayer-*` 的临时验证目录；它不扩大产品或外部系统范围。
2. 所有写操作保持最小作用域、create-only 或 append-only；删除、停止和回收之前先
   只读解析绝对目标或精确进程命令行。禁止对 workspace、home、根目录或未解析变量
   执行递归破坏操作。
3. 不执行远端 push、PR 合并、部署、消息发送、系统级包安装或永久服务配置，除非
   用户随后明确授权。测试依赖只允许安装到已有项目 venv 或用户临时目录。
4. 凭据、身份签名密钥、数据库 DSN 和 Agent 登录材料不得写入源控、日志或传给
   Agent worktree；错误消息不得回显 DSN 密码。
5. sandbox、身份、预算、worker lease 和状态事务均默认拒绝：缺少可验证能力、过期
   lease、越权、超预算、陈旧版本或证据不完整时，在副作用之前停止。
6. 临时监听器、数据库和测试 worker 在证据取得后立即停止；因监督器自动重启时，
   必须定位并停止本次命令对应的父级监督进程，不影响其他进程。
7. 每项材料变更和验证结果继续追加到开发日志；不能以测试 fixture 或能力声明替代
   实际负向测试。

## 后果

- 长时任务可以继续自主推进，但操作授权不会随着运行时间或主机权限自然扩张。
- 部分生产级验证会在本机能力不足时明确留作外部证据，不通过弱化政策伪装成功。
- 临时工具下载会占用 `/var/tmp`，但不修改系统包数据库；是否删除这些可复现实验
  目录必须在验证结束后按精确路径另行判断。
